MOSCOW TRANSIT — FREE PWA EDITION
================================

ЦЕЛЬ
Бесплатный путь для личного использования без macOS и без Apple Developer Program: установить веб-приложение на домашний экран iPhone. Это НЕ настоящий WidgetKit-виджет и не нативное приложение.

ЧТО ЕСТЬ
- Чёрный мобильный интерфейс.
- Сохранение личного маршрута в localStorage.
- Обратное направление.
- Открытие поиска/маршрута в Яндекс Картах.
- Геолокация только после явного нажатия и системного разрешения.
- PWA manifest, иконка, service worker для базового офлайн-кэша.

ЗАПУСК/РАЗМЕЩЕНИЕ
Для Add to Home Screen с корректной PWA-установкой размести содержимое папки на HTTPS-хостинге. Можно использовать бесплатный статический хостинг, например GitHub Pages (репозиторий должен быть публичным, если используешь бесплатный тариф GitHub Pages; не клади туда секреты). После публикации:
1. Открой адрес в Safari на iPhone.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Оставь «Открывать как веб-приложение» включённым, нажми «Добавить».
5. Запусти с новой иконки.

Локально открыть index.html можно для проверки дизайна, но service worker и геолокация обычно требуют HTTPS/localhost. Чтобы разместить на GitHub Pages, загрузи все файлы этой папки в корень репозитория и включи Pages в настройках репозитория.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Реальные прогнозы прибытия автобусов не подключены.
- Яндекс Карты открываются для поиска/построения; расчёт маршрута выполняет внешний сервис.
- Это веб-приложение, не системный виджет iOS. PWA не может показывать собственный WidgetKit на домашнем экране или Dynamic Island.
- Для настоящего WidgetKit/ActivityKit нужен нативный iOS-проект и сборка в macOS/Xcode или совместимой облачной среде.
- Бесплатная нативная установка через Xcode Personal Team требует периодического переподписывания (профили обычно действуют 7 дней), поэтому для требования «настроить один раз» PWA — самый практичный бесплатный вариант.
